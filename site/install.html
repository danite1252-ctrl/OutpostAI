Install Outpost

Outpost lives on one computer in your home, and everything else connects to it. Start with a Windows PC or a Linux server, then add your phones.

A Windows PC

The quickest start. Outpost runs while the PC is on, and keeps going in the tray when you close the window.

Windows steps

A Linux server

For a household that wants it always on. No screen needed: you set it up and use it from your PC and phones.

Your Android phone

Chat, create and talk to Outpost from your phone, once it's running on a PC or server.

On a Windows PC

About ten minutes, plus downloading a model.

What you need
EnoughBetter
Windows10 or 11, 64-bit
Graphics cardNVIDIA with 8 GB, for chat and picturesNVIDIA with 16 GB or more, for video and training characters
Memory16 GB32 GB
Free disk space30 GB100 GB or more, as models are large

  1. Download the installer

    Get Outpost_version_x64-setup.exe from the latest release.

    Open the latest release

  2. Run it

    Windows may say "Windows protected your PC", because the installer isn't signed with a paid certificate yet. Press More info, then Run anyway. It installs for your Windows user only, with no administrator needed, and adds Outpost to the Start menu.

  3. Make yourself the owner

    Choose your name and a PIN. The owner looks after accounts, models and connections.

  4. Install the engines

    Outpost offers the parts it needs for chat, pictures and video, and voice. Each downloads once and Outpost keeps it up to date. You can add any of them later in Settings › Engines.

  5. Get a chat model

    Open Models. Outpost suggests the ones that fit your graphics card; download one and start chatting.

  6. Add your household

    In Settings › Accounts, add each person. Everyone picks their name when Outpost opens and signs in with their own PIN.

Closing the window keeps Outpost running in the system tray, by the clock, so phones and long jobs keep working. Right-click the tray icon and choose Quit Outpost to stop it.

On a Linux server

The server holds everything: accounts, chats, pictures and models. Your PCs and phones pair with it, and nobody needs to log in to the server after setup.

What you need
The serverA Linux machine that stays on, such as Ubuntu. A virtual machine works if the graphics card is passed through to it.
Graphics cardNVIDIA, with its driver installed. 8 GB runs chat and pictures; a PC in the house can lend a bigger card for the rest.
Disk space100 GB or more for models.
A Windows PCWith the Outpost desktop app, to set up the owner account.

  1. Install Outpost on the server

    Sign in as the user Outpost should run as, and run:

    curl -fsSL https://github.com/danite1252-ctrl/OutpostAI/releases/latest/download/install.sh | bash

    It downloads the newest release, checks it hasn't been tampered with, sets Outpost up to run in the background, and shows a setup code and three check words. Keep them on screen for step 4.

  2. Keep it running at boot

    So Outpost starts with the server, even when nobody is logged in:

    sudo loginctl enable-linger $USER

  3. Connect from your PC

    Install the desktop app on a Windows PC (see above). On its first screen, choose Connect to an Outpost server and type the server's address on your network.

  4. Check the words, then make yourself the owner

    The app shows three check words. They must match the server's: if they don't, something else is answering at that address, so stop there. Then enter the setup code, your name and a PIN. That PC becomes your first paired device.

    The setup code works once and lasts 30 minutes. If it runs out, the full server guide shows how to get a new one.

  5. Pair phones and invite people

    From any paired device, Connections › Pair a device shows a QR code for your phones. Settings › Accounts › Make an invite lets each person choose their own PIN on their own device.

Worth doing next

  • Lend a bigger graphics card. On a gaming PC using the server, Settings › Server › Lend this PC's graphics card runs big models, video and training there, and pauses while you play.
  • Give the server some swap space, so big video and 3D jobs slow down rather than running out of memory.
  • Limit it to your home network with the server's firewall.
  • Keep coding builds sandboxed by installing bubblewrap: sudo apt install bubblewrap.
  • Use it away from home with Tailscale, a private network between your own devices.

Running the install command again updates Outpost, and owners can also update it from the desktop or phone app. The full server guide covers all of the above in detail.

On your Android phone

You'll need Outpost running on a PC or server first. The phone app connects only to your Outpost, encrypted.

  1. Download the app

    On the phone, open the latest release and download Outpost-version.apk.

    Open the latest release

  2. Install it

    Open the download. Android asks you to allow installs from your browser or file manager the first time: allow it, then press Install.

  3. Show a pairing code

    On a PC with Outpost, open Connections and press Pair a phone (on a server, Pair a device). If Outpost runs on that PC itself, first turn on Allow other devices on my network there and restart Outpost.

  4. Scan it and sign in

    In the phone app, scan the QR code, check the three words match the ones on the PC, then sign in with your PIN. If someone sent you an invite, scan or open that instead and pick your own PIN.

The app updates itself: new versions download in the background and install when you press Restart to update, and you stay paired. To use Outpost away from home, set up Tailscale on the phone and on your Outpost.
